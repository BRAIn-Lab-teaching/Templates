# ИИИ МФТИ: шаблон презентации PowerPoint

Шаблон презентации в бренде **ИИИ МФТИ** (Институт искусственного интеллекта
МФТИ) для PowerPoint, Keynote и Google Slides. Формат 16:9, тёмно-синяя и
барвинковая палитра, шрифт Montserrat, логотипы МФТИ + ИИИ на русском и
английском, градиентная плашка заголовка.
[Шаблон в Google Slides](https://docs.google.com/presentation/d/1kO26Wkvut_Fq_815SXgKZ8tEGGAQh7l0/edit?usp=sharing)

Это отдельный бренд, не BrainLab. Для презентаций лаборатории берите
[`Presentation_pptx`](../Presentation_pptx/README.md) (PowerPoint) или
[`Presentation_BrainLab`](../Presentation_BrainLab/README.md) (LaTeX).

> **Скилл для Claude:** [`iii-presentation.skill`](iii-presentation.skill)
> собирает `.pptx` в бренде ИИИ МФТИ из плана, заметок или текста, а также
> переоформляет готовую презентацию. Русский и английский. Как установить — в
> [корневом README](../README.md#скиллы-для-claude).

## Как пользоваться

1. Откройте шаблон в [Google Slides](https://docs.google.com/presentation/d/1kO26Wkvut_Fq_815SXgKZ8tEGGAQh7l0/edit?usp=sharing)
   и сделайте копию (Файл → Создать копию) или скачайте `.pptx` (Файл → Скачать →
   Microsoft PowerPoint). Файла шаблона в репозитории нет — только по ссылке.
2. Выберите подходящие слайды, продублируйте их и замените текст. Лишние удалите.
