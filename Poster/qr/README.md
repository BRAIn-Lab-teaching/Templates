# QR-коды

Картинки для `\addqr`, `\qrcodes` и `qrbox`. Папку можно поменять опцией `qrdir`.

## Что лежит в шаблоне

| Файл | Куда ведёт | Подпись по умолчанию |
|---|---|---|
| `x-qr.png` | https://x.com/lab4brain | `\qrlabelx` — X (Twitter) |
| `lab-tg.png` | https://t.me/brainlaboratory | `\qrlabeltg` — Telegram |
| `linkedin-qr.png` | https://www.linkedin.com/company/brain-lab-optimization-and-beyond/ | `\qrlabellinkedin` — LinkedIn |

`\qrcodes` и пустой `\begin{qrbox}{...}\end{qrbox}` выводят эти три кода и ещё
`own-tg.png` — ваш личный Telegram (`\qrlabelowntg` — My Telegram). Его файла в
шаблоне нет: положите свой, иначе на его месте будет рамка-заглушка с именем файла.

Подпись меняется так:

```latex
\renewcommand{\qrlabelowntg}{Telegram: @username}
```

Если личный код не нужен, перечислите коды сами:

```latex
\begin{qrbox}{Contacts}
\addqr{x-qr.png=\qrlabelx, lab-tg.png=\qrlabeltg, linkedin-qr.png=\qrlabellinkedin}
\end{qrbox}
```

## Как сделать свой код, чтобы он сканировался

- **PNG от 1000 px по стороне**, чёрный на белом. Картинка всё равно масштабируется
  под `qrsize`, так что большая не помешает, а маленькая станет мыльной.
- **Логотип в центре** — только при уровне коррекции M и выше и не больше ~5%
  площади кода. Коды в шаблоне сделаны так: у X и Telegram уровень H, у LinkedIn — M.
- **Короткая ссылка — меньше модулей.** Чем длиннее URL, тем мельче квадратики при
  том же размере кода. Длинные ссылки лучше сокращать или не перегружать параметрами.
- **Белое поле вокруг** не обрезайте: без него многие телефоны код не находят.
- **Проверьте с печати или с экрана на расстоянии** — с того места, откуда будут
  сканировать постер. Ориентир: код читается с расстояния примерно в 10 раз больше
  его стороны (6 см → около 60 см).
